# Dev Ataşehir Kadın Voleybol

Dev Ataşehir Spor Kulübü Kadınlar 2. Ligi için hazırlanan modern takım, sporcu, teknik ekip, puan durumu ve 18 haftalık fikstür sitesi.

## Canlı web

- [GitHub Pages sitesini aç](https://sporone.github.io/dev-atasehir-kadin-voleybol/)

## Geliştirme

```bash
npm install
npm run dev
npm run build:pages
```

Site içeriği `app/`, görseller ve takım logoları `public/` klasöründe bulunur. GitHub Pages çıktısı `docs/` klasöründe üretilir.
